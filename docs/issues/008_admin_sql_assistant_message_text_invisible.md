## What to build

Fix two text rendering bugs in the Admin SQL Assistant chat panel observed in
a production screenshot taken 2026-06-30:

1. **User message text invisible** — The gold (ipl-gold) message bubble renders
   correctly, but the navy text inside it is completely invisible. The outer
   floating container carries `select-none` which is not reset on the inner chat
   panel, and the chat panel itself has no explicit text-color reset. The
   `pointer-events-auto` div for the chat window must also add `select-auto` so
   that CSS `user-select` and any related rendering is reset for all children.

2. **Messages overflow horizontally** — Assistant and user message text clips
   at the right edge of the visible chat area instead of wrapping. The message
   bubble containers need `overflow-hidden` and `break-words` (or
   `overflow-wrap: break-word`) to prevent horizontal overflow. The chat messages
   area itself should also use `overflow-x-hidden`.

## Acceptance criteria

- [ ] User message text (navy on gold bubble) is legible and fully visible.
- [ ] Assistant message text wraps inside its bubble and does not clip
      horizontally.
- [ ] The outer `select-none` on the floating container does not prevent text
      rendering or selection inside the chat panel.
- [ ] No regression to the background-color, auto-scroll, or markdown fixes
      from PR #27.
